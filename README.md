# Hospital Noise Management System 🏥

A **Digital Logic Design hardware project** designed to monitor noise conditions across four hospital rooms using combinational logic circuits.

## 📌 Overview

The **Hospital Noise Management System** monitors four hospital rooms using four digital inputs.

* **1** → Noise is detected in the room
* **0** → No noise is detected in the room

Based on the four inputs:

* 💡 **Progressive LEDs** indicate the number of rooms where noise is detected.
* 🔢 A **1-digit 7-segment display** shows the total number of noisy rooms from **0 to 4**.
* ⚠️ A **warning LED** turns ON when noise is detected in **3 or more rooms**.

## ⚙️ Logic Design

The system is implemented entirely using **combinational digital logic** without the use of a microcontroller or programmable device.

The circuit uses basic logic gates such as:

* AND
* OR
* NOT
* XOR
* XNOR
* NAND
* NOR

The project demonstrates the practical implementation of **Boolean algebra, truth tables, logic simplification, and combinational circuit design**.

## 🔧 Hardware Components

* Digital input switches
* **AND×13**
* **OR×12**
* **XOR×1**
* **XNOR×1**
* **NOT×2**
* LEDs
* 1-digit 7-segment display
* Breadboard
* Jumper wires
* Power supply
