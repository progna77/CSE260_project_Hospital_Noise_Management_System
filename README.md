Hospital Noise Management System 🏥

A Digital Logic Design hardware project that monitors noise conditions across four hospital rooms using basic digital logic gates.

Overview

The system has four digital inputs, representing four hospital rooms. A value of 1 indicates noise detected in a room, while 0 indicates no noise.

Based on the inputs:

* 💡 LEDs light up progressively according to the number of noisy rooms.
* 🔢 A 1-digit 7-segment display shows the total number of noisy rooms (0–4).
* ⚠️ A warning LED turns ON when 3 or more rooms have noise detected.

Logic Design

The circuit is implemented using basic logic gates, including:

* AND
* OR
* NOT
* XOR
* XNOR
* NAND
* NOR

The project demonstrates the practical application of Boolean logic and combinational digital circuits without using a microcontroller or programmable device.

Hardware Components

* Digital input switches
* Basic logic gates
* LEDs
* 1-digit 7-segment display
* Warning LED
* Breadboard
* Connecting wires
* Power supply
